DE GOUDEN STAP — AANPASBARE WEBSITE

Open index.html om de website te bekijken.
Open admin.html om teksten, kleuren, categorieën en producten aan te passen.

BELANGRIJK:
- De beheerpagina slaat wijzigingen op in de browser (localStorage).
- Voor GitHub Pages is dit een eenvoudige statische oplossing.
- Afbeeldingen staan in /assets.
- Wil je wijzigingen voor ALLE bezoekers centraal opslaan, dan is een echte database/CMS nodig.
